# 渠道建设部导航站

一个为渠道建设部团队打造的内部工具与资源导航网站，采用 MONO 极简美学设计，提供高效、清爽的使用体验。

![MONO Skin Preview](./assets/images/preview.png)

## ✨ 特性

### 🎨 MONO 极简美学
- 单色主义设计，专注内容本身
- 蓝色系 (#2563eb) 作为强调色
- 深色/浅色主题自动切换

### 📱 响应式设计
- 完美适配桌面、平板、手机
- 移动端优化导航体验

### 🔍 智能搜索
- 实时搜索工具和资源
- ⌘K 快捷键快速唤起
- 支持分类筛选

### 🏷️ 分类管理
- 7 大分类：数据与汇报、素材创作、内容输出、广告投放、客户转化、其他工具
- 20+ 常用工具和平台
- 清晰的信息架构

## 🚀 快速开始

### 在线访问
直接访问 GitHub Pages 部署地址：
https://cyhzzz.github.io/ChannelDevelopmentDepartmentWiki/

### 本地开发
```bash
# 克隆仓库
git clone https://github.com/cyhzzz/ChannelDevelopmentDepartmentWiki.git

# 进入目录
cd ChannelDevelopmentDepartmentWiki

# 使用任意静态服务器运行
# Python 3
python -m http.server 8000

# Node.js
npx serve

# 或使用 VS Code Live Server 插件
```

## 🎨 皮肤系统

### MONO 极简版 (mono.html)
- 单色主义设计
- 蓝色强调色
- 深色/浅色主题
- 分类筛选
- 实时搜索
- 响应式布局

### 经典版 (classic.html)
- Webstack 主题
- 卡片式布局
- 侧边栏导航
- 分类管理

## 🛠️ 技术栈

- **HTML5** - 语义化标记

- **JavaScript** - 原生脚本
- **CSS Variables** - 主题切换
- **CSS Grid** - 布局系统
- **Flexbox** - 弹性布局
